# 硬盘与电池健康查看器

**Drive & Battery Health Viewer**

一款用于查看 Windows 电脑硬盘状态、电池健康情况等设备信息的轻量级工具，支持保存和浏览历史检测记录。

## 主要功能

- 查看硬盘型号、容量、接口、固件版本和健康状态
- 读取 NVMe SMART 健康信息
- 查看硬盘温度、通电时间、通电次数、总读取量和总写入量
- 查看电池设计容量、当前满充容量、健康度和循环次数
- 自动保存并浏览历史检测记录
- 支持导出检测报告
- 支持隐藏硬盘和电池序列号
- 支持简体中文、英语、俄语、法语、德语、韩语和日语
- 只读获取设备信息，不进行测速、擦写、修复或固件更新

## 系统要求

- Windows 7 或更高版本
- 64 位操作系统
- 部分硬件信息可能需要管理员权限

> RAID、Intel VMD/RST、USB 转接设备或旧版 Windows 可能无法提供完整的 SMART 信息，这通常是驱动或系统接口限制，并不代表硬盘存在故障。

## 隐私说明

检测报告可能包含硬盘和电池序列号。

公开发布、转发或上传报告前，建议启用软件中的“隐藏序列号”功能，或手动删除相关信息。
