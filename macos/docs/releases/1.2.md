# macOS 1.2

## 新增功能

- 采用全新界面设计，优化概览、历史和设置中的信息排布与文字呈现。
- 新增四档显示大小，并支持在历史报告中独立调节文字大小。
- 精简顶部导航，将关于信息、更新日志和检查更新集中到设置。
- 新增系统电池校准状态识别、菜单栏循环箭头图标与简明说明。
- 识别 macOS“立即充满电”的临时停用状态，保留原充电上限设置。
- 检查更新时可查看新版内容，并在应用内下载、安装及重新启动。

## 问题修复

- 系统校准或临时允许充满时，不再错误地显示充电保护失败。
- 修复打开更新日志时无法正常退出应用的问题。
