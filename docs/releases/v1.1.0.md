# macOS v1.1.0

macOS v1.1.0 是一次较大的原生版更新，在保持硬盘与健康数据只读的基础上，新增 Apple Silicon Mac 充电保护、诊断日志和多项界面及可靠性改进。

## 新增功能

- 新增 Apple Silicon Mac 电池充电保护，支持固定充电上限、“本次充满”以及菜单栏状态与快捷控制。
- 在 macOS 15.8 上使用 PowerUI 原生 80% 充电上限，达到上限后保持电源适配器供电。
- 为 iMac、Mac mini、Mac Studio 等无电池桌面 Mac 重新设计“电池”区域的空状态界面。
- 新增可按时间范围导出的隐私友好诊断日志。
- 新增概览中的非正常关机次数与错误日志条目显示。
- 新增版本更新后的轻打扰式更新日志提示；公开版本号或内部构建号变化时都会一次性显示。
- 在“关于”页面新增检查更新入口。

## 充电保护兼容性

- **Apple Silicon + macOS 13 至 26.3（macOS 15.8 除外）**：在检测到受支持的控制能力后，提供 80% / 85% / 90% / 95% / 100% 多档位。
- **Apple Silicon + macOS 15.8**：80% 用于启用 Apple 原生上限，100% 用于关闭充电保护；85% / 90% / 95% 显示但不可选。
- **Apple Silicon + macOS 26.4 及以上**：默认推荐使用 macOS 系统功能。用户仍可明确选择本软件管理；按引导完成系统设置确认后，可使用相同的多档位界面。
- **Intel Mac**：电池充电由 macOS 管理，不开放软件充电保护。

软件控制优先使用保持适配器供电的 CHTE，并兼容旧式 Apple Silicon 固件的 CH0B+CH0C。不会把会隔离适配器的 CHIE 作为普通限充兜底。

## 优化改进

- 改进外接 USB、Thunderbolt 及支持 SAT 透传设备的信息识别与只读检测兼容性。
- 增强硬件查询超时、取消、热插拔和设备身份匹配的稳定性，避免应用旧结果。
- 优化历史记录多选、报告导出图标和内置 SSD 工作时间说明。
- 充电 helper 与菜单栏 Agent 在应用更新时会校验版本并完整替换不一致的旧组件；设置页可停用并卸载充电辅助程序。
